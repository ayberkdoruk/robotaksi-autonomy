# ortak/

Ekipteki **herkesin** kullandığı paketler. Buradaki bir değişiklik bütün sürüş yöntemlerini etkiler;
değiştirmeden önce ekiple konuşun.

| Paket | İçerik |
|---|---|
| `robotaksi_msgs` | Ortak mesaj tipleri (`EngelDurumu`, `Nesne`, `NesneDizisi`, `ZeminDurumu`, araç komutu `AracKomutu`) |
| `robotaksi_baslat` | Ortak ROS ortamı (`ros_ortami.sh`, Fast DDS ayarı); ileride aracın tamamını başlatan launch dosyaları |
